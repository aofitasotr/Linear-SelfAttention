# Custom BERT: Линейное внимание, позиционное кодирование и разреженность

## Описание проекта

Проект посвящён исследованию и развитию **линейного внимания** в BERT для анализа тональности отзывов. Основной акцент — на:

- **Позиционном кодировании**: реализованы механизмы, позволяющие учитывать позицию токенов в последовательности, что критично для понимания структуры текста.
- **Разреженности внимания**: внедрены методы, позволяющие эффективно моделировать длинные последовательности, снижая вычислительные затраты и улучшая масштабируемость.

В проекте представлены:

- Классические и кастомные реализации линейного внимания
- Варианты с позиционным кодированием (`LinearContextAttentionPosEnc`)
- Варианты с разреженным вниманием (`LinearContextAttentionDilated`)
- Гибкая настройка архитектуры BERT (замена/добавление/удаление слоёв)
- Кросс-валидация, автоматическое разделение датасета, подробный логгинг

- `main.py` — точка входа, запускает обучение через аргументы командной строки.
- `test_sentiment_bert.py` — парсер аргументов, настройка эксперимента.
- `training.py` — основной модуль обучения, поддерживает кросс-валидацию, замену/добавление слоёв, логгинг, сохранение результатов.
- `custom_attention.py` — реализации кастомных механизмов внимания.
- `dataset_utils.py` — подготовка и разделение датасетов, класс `ReviewDataset` для HuggingFace Trainer.
- `evaluation.py` — скрипты для оценки моделей и инференса.
- `loader.py` — интерфейс и класс для ленивой загрузки моделей и токенизаторов.
- `logging_utils.py` — логгинг, сохранение результатов, управление лог-файлами.
- `config.json` — конфигурации экспериментов (гиперпараметры, архитектура, классы).

# Подробнее о реализованных механизмах внимания

## 1. От классического внимания к линейному

Классический механизм внимания в Transformer (Vaswani et al., 2017) требует вычисления матрицы

$$
QK^T
$$

размера

$$
n \times n
$$

что даёт квадратичную сложность

$$
O(n^2)
$$

Это ограничивает обработку длинных текстов.

**Линейное внимание** снижает сложность до

$$
O(n)
$$

В реализации `LinearContextAttention` контекстное представление токена вычисляется как:

$$
C_i = \frac{1}{n-1}\sum_{j \ne i} V_j
$$

где

* $V_j$ — вектор значения токена $j$ после линейной проекции.

Такой подход не требует вычисления $QK^T$.

---

# 2. Позиционное кодирование в линейном внимании

`LinearContextAttentionPosEnc`

Линейное внимание не различает позиции токенов, поэтому добавляется позиционная информация.

Используется **синусоидальное позиционное кодирование**, но вместо сложения с эмбеддингами выполняется **модуляция значений**.

Для токена на позиции $i$:

$$
V_i' = V_i (1 + scale_h \cdot PE_i)
$$

где:

* $PE_i$ — синусоидальный позиционный вектор
* $scale_h$ — обучаемый параметр для каждой головы внимания

После этого выполняется линейное усреднение.

---

# 3. Разреженное внимание

`LinearContextAttentionDilated`

Каждая голова внимания обрабатывает только часть токенов.

Головы получают разные **дилатации**:

```
1, 2, 4, 8, ...
```

Для головы с дилатацией $d$ и смещением $o$ выбираются позиции:

$$
p = o + k \cdot d
$$

где

$$
k = 0,1,2,... \quad (p < n)
$$

Контекст считается только по этим позициям.

### Преимущества

* **Снижение вычислительной сложности**
* **Многомасштабный контекст**
* **Захват дальних зависимостей**

---

# 4. Связь с задачей анализа тональности

В сентимент-анализе важна **локальность контекста**.

Например:

```
не хороший
очень плохой
```

Отрицания и модификаторы влияют на тональность в радиусе **2–4 токенов**.

Базовое линейное внимание с равными весами не улавливает эту структуру.

Добавление:

* позиционного кодирования
* дилатированного внимания

позволяет модели учитывать:

* локальные зависимости
* дальние синтаксические связи.

---

Все механизмы реализованы в `custom_attention.py` и могут быть интегрированы в BERT через функцию:

```
inject_linear_attention
```

Гибкость архитектуры позволяет экспериментировать с разными конфигурациями и анализировать их влияние на качество сентимент-анализа.
